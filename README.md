## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Kolajin landing
- Built on TanStack Start (Next.js isn't supported in this environment); 3D via React Three Fiber, scroll via GSAP ScrollTrigger, UI motion via Framer Motion.
- Bowl photos were AI-generated with transparent backgrounds. Replace `src/assets/ash.png`, `shole.png`, `halim.png` to swap them (dish copy lives in `src/lib/dishes.ts`).
- Font: change `--font-persian` in `src/styles.css` and the Google Fonts link in `src/routes/__root.tsx`.
